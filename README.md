EMBERLINE — a round-based tactical FPS on three.js. You are Vanguard, alone against four Jackals in Dustline Yard: carry the Spike to the Reactor, plant it and hold, or eliminate the whole squad. First to 5 rounds takes the match. Headshots deal double damage, recoil and spread punish firing on the move, and money earned each round buys rifles, a DMR and flash grenades.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080 in desktop Chrome
```
